# COSC 304 - Introduction to Database Systems<br>Lab 3: Writing SQL Queries - Local Setup

Lab 3 uses the same MySQL Docker environment as Lab 2.

Follow the [Lab 2 local setup instructions](../../lab2/setup).

The Lab 2 setup creates all databases required for this lab, including:

* `shipment` — used for the Lab 3 assignment
* `university` — used for the Lab 3 practice questions

If you already completed the Lab 2 setup, you do not need to create another container. Start the existing environment from the Lab 2 setup directory:

```text
cd cosc_304/labs/lab2/setup
docker compose up -d
```

You can then connect to MySQL as described in the Lab 2 setup instructions.
