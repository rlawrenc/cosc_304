COSC 304: Java Web Programming Examples

Examples of JSP, servlets, JDBC, sessions, JavaScript, and AJAX. The JDBC examples use the SQL Server workson database.

1. JSP Basics

  • Hello World (JSP) — Scriptlets, JSP declarations, and request information.
  • Hello World Again — Practice answer using a Java loop in JSP.
  • JavaScript generated by JSP — Server-side JSP generates client-side JavaScript.

2. Forms, Sessions, and Login

  • Store data in a session — Create and store an array of integers.
  • Retrieve session data — Read the array on another request.
  • Login page — Submit credentials and establish an authenticated session.
  • Protected page — Check authentication before showing content.
  • Logout — Invalidate the current session.

Login demonstration only: username test, password test#1234. Not production authentication.

3. JDBC and SQL Server

  • Basic JDBC query — Execute SQL and display a ResultSet.
  • Employee search (prepared statement) — Search using optional name and department parameters.
  • Employee search (unsafe SQL) — Demonstration of SQL injection caused by string concatenation.
  • Employee/project search — Join tables and use multiple optional search filters.
  • Departments, projects, and employees — Reuse prepared statements for related queries.

The unsafe SQL example is intentionally vulnerable and is for local classroom demonstration only.

4. JavaScript and AJAX

  • Validate an integer — Client-side JavaScript validation.
  • Validate username and email — AJAX request to a JSP validator.
  • Country and province/state — AJAX updates a dropdown using SQL Server data.

5. Servlets

  • Hello World (Servlet) — Generate HTML from a Java servlet.
  • JDBC query (Servlet) — Query SQL Server using JDBC.
  • Employee search (Servlet) — HTML form calling a servlet with prepared statements.
