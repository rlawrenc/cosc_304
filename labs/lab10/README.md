Complete your project by adding more features. Use the [feature marking checklist](develop/developProjectFeatureMarking.docx) to plan what features you will implement. The project is worth 50 marks, with up to 10 additional bonus marks available. Marks are awarded based on correct functionality, completeness, and quality. It is also possible to suggest your own features for credit. Clear documentation and a feature walkthrough are essential for marking.

#### Details:

1. Get inspired for your store and the products it sells by reviewing some of the [best past projects](https://cmps-people.ok.ubc.ca/rlawrenc/teaching/304/Project/index.html). You should sell different products than the sample products provided in lab 7.

2. Submit a ZIP file on Canvas containing your complete project code, documentation, and feature walkthrough.

3. Include a README with instructions to run your project, the website URL (if deployed), login credentials, and a walkthrough of the features implemented. The project should include any required database setup and sample data. TAs must be able to run and test the features without modifying your code.

4. The [feature marking checklist](develop/developProjectFeatureMarking.docx) must be included when submitting your documentation.

5. Hosting your website on a publicly accessible server is encouraged but not required.

## [Analysis](analyze/) Stream

Building upon your prior analysis work, complete your project by producing a report to the CEO. This report should help ACME answer key questions about its products, customers, and warehouse inventory. This is an open-ended analysis and predictions with the focus on your process and documentation more than the actual results. Use the [feature marking checklist](analyze/analyzeProjectFeatureMarking.docx) to plan what features you will implement. The project is worth 50 marks, with up to 10 additional bonus marks available. Marks are awarded based on correct functionality, completeness, and quality. It is also possible to suggest your own features for credit. Proper documentation is very important, especially any Internet sources used.

#### Details:

1. Submit your report document, Excel file, and any other files in a zip on Canvas.

2. Your report should summarize your most important findings and provide actionable recommendations supported by your analysis. Explain the methods used, key assumptions, and any limitations of your conclusions. Include visualizations where they help communicate the results. Include the SQL queries, Excel calculations, and supporting data necessary to verify your results.

3. The [feature marking checklist](analyze/analyzeProjectFeatureMarking.docx) must be included when submitting your documentation.
